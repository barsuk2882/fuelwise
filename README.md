# FuelWise V3 — Route First

Актуальная версия приложения с визуальным направлением Route First. Создана отдельно от рабочей папки V2, чтобы сохранить исходную реализацию.

## Визуальное направление

- Карта маршрута — главное рабочее полотно; форма маршрута и автомобиля собрана в компактной левой панели.
- Тёмная тема включена по умолчанию; переключение на светлую тему сохранено.
- Линия маршрута выделена ярким голубым цветом, точки АЗС имеют одинаковый янтарный цвет на обеих картах.
- На телефоне точка поиска занимает доступную ширину, а кнопки «Найти» и «На карте» остаются удобными для нажатия; кнопка расчёта закреплена у нижнего края формы.
- Появление рабочей области, результата и состояния кнопок анимировано короткими переходами. При `prefers-reduced-motion` анимации отключаются.
- Кэш PWA и записи localStorage используют пространство `fuelwise.v3`, чтобы предпросмотр не затрагивал состояние V2.

## Назначение

Это проверенная версия пилотного приложения с вводом произвольных адресов, прокладкой автомобильного маршрута и сохранением последних 10 расчётов. Проект доступен в браузере и устанавливается как веб-приложение на поддерживаемых смартфонах.

**Открыть приложение:** [barsuk2882.github.io/fuelwise](https://barsuk2882.github.io/fuelwise/)

## Возможности

- Поиск точек А и Б по адресу или названию места после нажатия кнопки «Найти»; варианты показывают адрес, тип объекта и степень совпадения.
- Выбор произвольной точки нажатием на карту.
- Построение дорожной линии и получение длины/времени маршрута через OSRM.
- Расчёт топлива, сравнение маршрутов, предупреждения и история последних 10 расчётов.
- Если цены топлива неизвестны, варианты называются «Короче», «Быстрее» и «Баланс расстояния и времени»; приложение сравнивает длину и время, не подменяя неизвестную стоимость нулём. При известной цене сравниваются стоимость и время.
- Денежные суммы отображаются в рублях (₽); цена топлива вводится в ₽/л.
- Повтор сохранённого маршрута без повторного поиска адресов: координаты и геометрия сохраняются в браузере.
- Карта и открытые данные АЗС отображаются отдельным блоком; наличие цен зависит от источника. Резервные точки АЗС не выдаются за свежие данные.
- Параметры автомобиля, цена, тема, геокодинговый кэш и история хранятся в пространстве localStorage с префиксом `fuelwise.v3`.
- PWA-оболочка использует отдельное пространство имён кэша `fuelwisev3-*`.

## Локальный запуск

Для локальной проверки в Windows запустите `start-fuelwise.bat` из папки проекта. Он запускает статический сервер на порту `8876` и открывает `http://localhost:8876/` после проверки ответа приложения. Оставьте окно сервера открытым. BAT сообщает, если сервер не запустился или порт занят. Для ручного запуска откройте терминал в папке проекта и выполните:

```text
python -m http.server 8876 --bind 127.0.0.1
```

Адрес `localhost` доступен только на том же компьютере. Для телефона и других устройств используйте HTTPS-ссылку на опубликованную версию.

## Источники и ограничения

- Адресный поиск выполняется только по кнопке, без автодополнения. Каждый запрос без кэшированного результата отправляет один поисковый запрос: сокращения нормализуются, контекст города добавляется автоматически, а ответы ранжируются по совпадению слов и номеров. Успешные результаты кэшируются в браузере до 24 часов; запросы сериализуются с интервалом не менее 1,1 секунды. Эти меры уменьшают нагрузку, но не отменяют ограничения поставщика: при ответе об ограничении нужно выдержать паузу или выбрать точку на карте.
- Маршруты строятся публичным демонстрационным сервером OSRM. Доступность, время ответа, покрытие и число альтернатив не гарантируются; для пилота не следует отправлять частые массовые запросы.
- Подложка карты сначала загружается с MIERUNE. Если тайлы не приходят или все запросы завершаются ошибкой, обе карты автоматически переключаются на резервный `tile.openstreetmap.org`; источник тайлов проверяется по событиям Leaflet, а при недоступности обоих источников появляется сообщение. На внешних публичных тайлах карта без интернета недоступна.
- Резервные тайлы OpenStreetMap предоставляются без платы, но без SLA и с ограничениями использования. Приложение запрашивает только видимую область, показывает обязательную атрибуцию и не загружает карту заранее. Для высокой или гарантированной нагрузки нужен выделенный поставщик либо собственный сервер.
- Цена за литр вводится пользователем, если проверенная цена не получена из данных АЗС. Цена из резервного списка станций не подставляется автоматически.
- Публичные источники могут менять правила использования или временно ограничивать запросы. Для более широкой эксплуатации следует подключить выделенный поставщик маршрутов/геокодирования с согласованными условиями или собственную инфраструктуру.

## Схема расчёта и история

Расчёты выполняются модулями `js/calculations.js` и `js/optimizer.js`. Для маршрута без свежих цен стоимость остаётся неопределённой, пока пользователь не укажет цену. История содержит подписи, координаты точек, геометрию, расстояние, время, параметры автомобиля, оценку стоимости и выбранный вариант. Сохраняются 10 последних записей. Записи старого формата без координат видны в истории, но автоматически повторить их нельзя.

## Структура основных модулей

- `js/app.js` — связывает форму, сервисы, расчёты и историю.
- `js/ui.js` — ввод и отображение состояния интерфейса.
- `js/map.js` — карта маршрута, выбор точки по клику и отрисовка маршрутов.
- `js/mapTiles.js` — общая подложка обеих карт, переход на резервный источник и сообщения об ошибках тайлов.
- `js/calculations.js` — формулы расхода и геометрические расчёты.
- `js/optimizer.js` — варианты поездки и план остановок.
- `js/storage.js` — безопасная работа с localStorage.
- `js/services/geocodingService.js` — поиск и кэширование адресов.
- `js/services/routingService.js` — запрос маршрута и обработка ответа OSRM.
- `js/services/fuelStationsService.js` — локальный справочник видов топлива и поиск АЗС около маршрута через сервис открытых данных.
- `js/services/liveFuelStationsService.live.js` и `js/moscowStationsMap.live.js` — отдельная карта АЗС.
- `cloudflare/stations-api-worker.js` — CORS-прокси к публичному API АЗС; его нужно развернуть отдельно и прописать URL в `js/services/stationsApiConfig.js`, прежде чем GitHub Pages сможет читать данные в браузере.
- `service-worker.js` — PWA-кэш с версионированием и удалением старых кэшей.

## Проверка вручную

1. Откройте приложение через BAT и выберите тип топлива.
2. Введите в точку А адрес или объект, нажмите «Найти» и выберите один из результатов; повторите для точки Б.
3. Нажмите «Рассчитать поездку»: должны появиться линия дороги, расстояние, время, топливные расчёты и история.
4. Повторите расчёт с другой ценой и каждым из трёх приоритетов.
5. Перезагрузите страницу и повторите запись из истории.
6. Проверьте неверную/короткую поисковую строку, одинаковые точки, отключённую сеть и выбор точек кликом по карте: сообщения должны оставаться понятными, приложение не должно зависать.
7. Откройте опубликованную HTTPS-ссылку на телефоне, проверьте мобильную вёрстку и при желании установите приложение через меню браузера.

## Принятые решения

- Демо-список точек и синтетические дороги удалены из пользовательского сценария. Демонстрационные заправки используются только как локальный справочник видов топлива; редактор демо-заправок удалён, поскольку он не управлял реальными данными карты и расчётов.
- Поиск адреса выполняется только по запросу пользователя, поскольку публичный геокодер не подходит для постоянного автодополнения.
- Если сетевой маршрут не получен, приложение показывает ошибку и не подменяет его прямой линией или демонстрационной геометрией.
- Снимки старой истории остаются видимыми, но кнопка повтора блокируется, если в записи нет координат и маршрута.
- Крупные изменения сначала проверяются в отдельной версии. После проверки содержимое итоговой папки синхронизируется с корнем GitHub-репозитория для публикации GitHub Pages.
