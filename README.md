# FuelWise V5

FuelWise помогает водителю спланировать поездку, оценить расход и стоимость топлива и выбрать заправки по пути. Пилот карты АЗС ориентирован на Москву и область. Приложение работает в браузере и поддерживает установку на главный экран телефона как PWA.

**Рабочая версия проекта — V5. Статус — предрелиз.** Холодный запуск и мобильные сценарии проверены в Chrome на Windows. Установка на физических Android и iPhone остаётся отдельной проверкой. [Открыть FuelWise на телефоне](https://barsuk2882.github.io/fuelwise/)

## Запуск в Windows

1. Скопируйте всю папку V5. На компьютере нужны Google Chrome и Python 3, доступный по команде `python` или `py -3`. Устанавливать пакеты проекта не требуется.
2. Дважды щёлкните [start-fuelwise.bat](start-fuelwise.bat). Дождитесь строки «FuelWise V5 готов». Оставьте окно открытым.
3. Откройте в Chrome [локальную V5](http://127.0.0.1:8876/). Для первого испытания с пустыми данными используйте новый профиль или новое окно инкогнито после закрытия всех предыдущих окон инкогнито. Для сохранения поездок между сеансами используйте обычный профиль.
4. Для остановки нажмите Ctrl+C в окне сервера. Если BAT сообщает о занятом порте, проверьте уже открытое окно V5. Адрес V5 использует порт **8876**. Запуск двойным щелчком по index.html не воспроизводит условия работы PWA.

## Первая поездка

Задайте начальную и конечную точки поиском или кнопкой «На карте». Укажите топливо и параметры автомобиля. Нажмите «Рассчитать поездку», сравните варианты «Дешевле», «Быстрее» и «Баланс». На карте АЗС нажмите «Обновить», откройте станцию и проверьте сведения именно о своём топливе. В истории можно снова открыть поездку, изменить параметры и пересчитать оценку.

Адреса для поиска получает внешний геокодер, координаты для нового маршрута — сервис маршрутизации. Цены и наличие зависят от наполнения источника. История, тема и параметры автомобиля хранятся в текущем браузере. Очистка данных сайта удаляет их. Для повторного открытия без сети предварительно откройте V5 онлайн и сохраните поездку.

## Проверка и установка на телефоне

Откройте публичный сайт в Chrome на Android или Safari на iPhone. Для установки на Android выберите в меню браузера установку приложения, на iPhone — «Поделиться» и «На экран Домой». Если у вас была V3, сохраните данные сайта, закройте старые вкладки и вновь откройте FuelWise. Проверьте тему, автомобиль и историю.

В V5 исправлены сравнение точек по координатам и чтение повреждённой истории с восстановлением пригодной копии V3. В холодном прогоне мобильной эмуляции пройдены 19 сценариев, модульных тестов — 25. Для повторной проверки из корня репозитория выполните команду Node.js ниже.

```powershell
node --test tests/*.test.mjs
```
